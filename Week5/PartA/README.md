# Week 5 - Part A: Embeddings Fundamentals

## Objective
Learn the basics of text embeddings, semantic similarity, and cosine similarity using the Gemini Embedding API.

## Concepts Covered
- Embeddings
- Semantic Similarity
- Cosine Similarity
- Meaning-based Search

## Files
- `embed_demo.py` - Generates embeddings and computes cosine similarity between different sentences.

## Tasks Completed

### Task 1
Compared two semantically similar sentences and one unrelated sentence using cosine similarity.

### Task 2
Printed the embedding length and displayed the first few embedding values.

### Task 3
Compared two sentences with opposite meanings and observed how embedding similarity behaves.

## Sample Output

```
Similar meaning score   : 0.8229
Unrelated meaning score : 0.5355

Embedding Length : 3072

Opposite sentence similarity : 0.7260
```

## Observation

- Similar sentences produced a higher similarity score than unrelated sentences.
- The embedding generated by Gemini contains 3072 numerical values.
- Individual numbers are not meaningful by themselves.
- Opposite sentences still have a relatively high similarity because embeddings capture overall semantic context rather than only positive or negative sentiment.
