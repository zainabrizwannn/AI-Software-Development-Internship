# Week 5 - Part C: Manual RAG Pipeline

## Objective

Build a Retrieval-Augmented Generation (RAG) pipeline from scratch using Gemini embeddings and ChromaDB.

## Concepts Covered

- Document Loading
- Text Chunking
- Embeddings
- Vector Database
- Semantic Retrieval
- Prompt Construction
- Answer Generation
- Source Attribution

## Features

- Loads text documents
- Splits documents into chunks
- Stores chunks in ChromaDB
- Retrieves relevant chunks
- Builds a prompt using retrieved context
- Generates answers using Gemini
- Displays source metadata
