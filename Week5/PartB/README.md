# Week 5 - Part B: Vector Databases

## Objective
Learn how a vector database stores embeddings and retrieves documents based on semantic similarity.

## Concepts Covered
- Vector Database
- ChromaDB
- Semantic Search
- Metadata Filtering
- Document Embeddings

## Files
- `chroma_demo.py` - Demonstrates creating a Chroma collection, adding documents, querying similar documents, filtering with metadata, and adding custom documents.

## How to Run

Install dependencies:

```bash
pip install chromadb
```

Run:

```bash
python chroma_demo.py
```

## Learning Outcomes

- Created a ChromaDB collection.
- Stored documents with metadata.
- Performed semantic search.
- Applied metadata filters.
- Added custom documents and queried them successfully.
